# Getting help

| You want to | Go to |
|---|---|
| Deploy TrnRT, or fix a start-up check | [docs/DEPLOY.md](docs/DEPLOY.md), then [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md) |
| Get a Trainium2 instance | [docs/AWS.md](docs/AWS.md) |
| Look up a flag or an environment variable | [docs/CONFIGURATION.md](docs/CONFIGURATION.md) |
| Call the API | [docs/API.md](docs/API.md) |
| Ask a question | [Discussions](https://github.com/RunanywhereAI/trnrt/discussions) |
| Report a bug or a regression | [an issue](https://github.com/RunanywhereAI/trnrt/issues/new/choose) |
| Report a security issue | [SECURITY.md](SECURITY.md) |
| Run TrnRT on your own capacity, or a new model | [founders@runanywhere.ai](mailto:founders@runanywhere.ai) |

To contribute, see [CONTRIBUTING.md](CONTRIBUTING.md).
